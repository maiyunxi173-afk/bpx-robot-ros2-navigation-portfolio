# BPX Hardware Demo Notes

The BPX hardware clip is available at [docs/media/bpx_physical_demo.mp4](media/bpx_physical_demo.mp4), with a lightweight [GIF preview](media/bpx_physical_preview.gif). It is a 21-second H.264 recording prepared for browser-compatible playback on GitHub.

What the clip shows:

- a BPX quadruped in the obstacle-course environment;
- the corresponding live map and robot-console view; and
- the physical setup used for the ROS 2 driver, localisation, SLAM and Nav2 integration workflow.

The clip is evidence of **hardware integration and functional navigation workflow**. It does not contain a ground-truth trajectory, repeated fixed-route trials, collision statistics, or a controlled success-rate measurement. It must therefore not be used to claim numerical localisation accuracy or navigation success rate.
